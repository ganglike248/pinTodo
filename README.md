# 📌 PinTodo

**완료할 때까지 알림창에서 사라지지 않는 안드로이드 할 일 앱**

할 일을 추가하면 알림창에 고정됩니다. 옆으로 밀어도, "모두 지우기"를 눌러도 다시 나타나고, **'완료' 버튼을 눌러야만** 사라져요.

> 현재 버전: **v0.4.4** (정식 출시 전) · Android 8.0(API 26) 이상 · Google Play 출시 준비 중

<br>

## 만든 이유

갤럭시 기본 리마인더나 캘린더 앱은 할 일을 알림으로 보여주지만, **알림을 옆으로 밀거나 지우면 그대로 사라지고 다시 뜨지 않아요.** 무심코 알림창을 정리하다 보면 해야 할 일까지 같이 지워져 버립니다.

"끝낼 때까지 눈앞에 계속 떠 있는 할 일"이 필요해서 만들었어요.

### 왜 일반적인 '고정 알림'만으로는 안 될까

안드로이드에는 원래 지울 수 없는 알림(`ongoing`)이 있지만, **Android 14(One UI 6)부터 사용자가 이런 알림도 밀어서 지울 수 있게 바뀌었어요.** 그래서 이 앱은 다음 방식을 함께 써요.

1. 알림이 지워지는 순간을 감지해(`deleteIntent`) **즉시 조용히 다시 띄우기**
2. 재부팅, 앱 업데이트, 시간 변경 뒤에도 **알림 자동 복원하기**
3. 앱이 강제 종료되어 알림이 사라졌으면 **앱을 열 때 복원하기**

<br>

## 주요 기능

### 알림창 고정
- 할 일마다 알림이 하나씩 생겨요.
- 밀어서 지워도 바로 다시 나타나요. 고정을 끄면 밀었을 때 이번 회차만 숨겨요.
- 알림 버튼: **[완료] [10분 뒤] [미루기…]**
  - 가운데 버튼은 설정에서 고른 "자주 쓰는 미루기"예요.
  - **미루기…**를 누르면 켜 둔 선택지(10분, 30분, 1시간, 3시간, 저녁 6시, 내일 아침 9시)가 시트로 나와요. 저녁 6시가 지났으면 다음 날 저녁 6시로 미뤄요.
- 알림을 누르면 해당 할 일의 수정 화면이 열려요.
- 제목 아래에 **정해 둔 일정**(예: `10/6(화) 오후 2:00 시작 · 오후 6:00까지`, `평일 오전 9:00–오후 6:00 반복`)이 함께 보여요. 메모가 있으면 메모 아래에 붙어요.
- 하루 안에 끝나는 할 일은 알림 머리글에 **종료까지 남은 시간**이 실시간으로 줄어들어요. 미뤘다가 다시 뜬 알림에는 "미룬 할 일"이 붙어요.

### 스마트워치 알림
- 갤럭시 워치, 화웨이 밴드 등 휴대폰과 연결된 워치에도 알림이 가요. 워치에서는 **[완료] [10분 뒤]** 버튼을 바로 누를 수 있어요.
- 워치는 고정(`ongoing`) 알림을 넘겨받지 않아서, 워치로 보낼 때는 고정 플래그 없이 "지우면 바로 다시 띄우기"로 고정을 유지해요.
- 한 번 밀어서 지운 알림은 휴대폰에만 다시 뜨고 워치에서는 사라져요. 새 회차나 미루기가 끝나면 다시 워치로 가요.
- **설정 > 알림창 · 홈 화면 > 스마트워치에도 알림**에서 끌 수 있어요. 워치 앱(Galaxy Wearable, Huawei Health 등)의 알림 설정에서 PinTodo가 켜져 있어야 해요.

### 알림 없는 할 일
- 할 일마다 **알림 받기**를 끌 수 있어요. 끄면 알림창에는 뜨지 않고 목록과 위젯에만 보여요.
- 빠른 추가에서는 "알림 없이"를 고르면 돼요. 새 할 일의 기본값은 설정에서 바꿀 수 있어요.

### 소리·진동은 처음 한 번만
- 알림 방식은 **무음 / 소리 / 진동 / 소리+진동** 중에서 고를 수 있어요.
- 소리와 진동은 **할 일이 처음 뜰 때 한 번만** 울려요. 밀었다가 다시 뜰 때, 재부팅이나 업데이트로 복원될 때는 조용히 표시돼요.
- 반복 할 일의 새 회차가 시작될 때와 미루기가 끝날 때만 다시 한 번 알려요.
- 알림 방식을 고를 때 **지금 휴대폰 모드에서 실제로 어떻게 울리는지** 함께 보여줘요.

  | 휴대폰 모드 | 소리 | 진동 | 소리+진동 |
  |---|---|---|---|
  | 소리 모드 | 소리만 | 진동만 | 둘 다 |
  | 진동 모드 | **진동으로 바뀜** | 진동 | 진동 |
  | 무음 / 방해 금지 | 알림창에만 표시 | 알림창에만 표시 | 알림창에만 표시 |

### 표시 기간 설정
| 일정 | 설명 | 예시 |
|---|---|---|
| **한 번** | 시작과 종료 시각을 지정해요. 비워두면 지금부터 완료할 때까지 표시돼요. | 오늘 오후 2:00 ~ 오후 6:00 |
| **매주 / 격주** | 요일과 하루 중 시간대를 지정해요. 그 시간에만 알림이 떠요. | 평일 오전 9:00 ~ 오후 6:00 |
| **매월** | 매월 같은 날. '말일'을 고르면 짧은 달에도 마지막 날에 떠요. | 매월 25일 오전 9:00 |
| **며칠마다** | 처음 정한 날부터 2~30일 간격으로. | 3일마다 오후 8:00 |

- 시각은 모두 **오전/오후 12시간제**로 보여요.
- 편집 화면에서 **시작·종료 칸을 고르면 바로 아래에 휠이 펼쳐져 있어요**(따로 눌러 열 필요 없음). 날짜는 오늘·내일 버튼이나 달력으로 골라요.
- 시작 시각은 빠른 선택(30분 뒤, 1시간 뒤, 내일 아침)으로도 정할 수 있어요.
- 반복 요일은 매일, 평일, 주말을 한 번에 고를 수 있어요.
- 반복은 **계속 / 날짜까지 / 횟수**로 끝낼 수 있어요(예: 10회 하고 끝내기).

### 체크리스트 · 색 라벨
- 할 일 안에 **체크리스트**를 만들 수 있어요. 목록 카드에서 "체크리스트 2/5"를 누르면 펼쳐서 바로 체크하고, 알림을 펼치면 ☑/☐ 목록이 보여요.
- **색 라벨**(빨강·주황·노랑·초록·파랑·보라)을 붙이면 목록·위젯에 점으로, 알림에는 아이콘 색으로 보여요.
- 편집 화면은 제목만 먼저 보이고, 메모·체크리스트는 **+ 메모 / + 체크리스트**를 눌러 꺼내요. 알림 방식(고정·소리·진동)은 한 줄 요약을 눌러 바꿔요.

### 글에서 날짜 자동 인식
- 제목이나 메모에 날짜·시각을 쓰면 **일정이 자동으로 맞춰져요.** 맞춘 뒤 "되돌리기"로 취소할 수 있고, 일정을 직접 바꾸면 그다음부터는 손대지 않아요.

  | 이렇게 쓰면 | 일정 |
  |---|---|
  | 내일 오후 3시 회의 | 내일 오후 3:00부터 |
  | 3시부터 5시까지 스터디 | 오후 3:00 ~ 오후 5:00 |
  | 금요일까지 보고서 | 지금부터 금요일 자정까지 |
  | 30분 뒤 전화 / 3일 뒤 택배 | 30분 뒤부터 / 3일 뒤 오전 9:00부터 |
  | 다음 주 월요일 2시, 10월 9일 저녁, 10/9 18:30 | 그 날짜·시각 |

  오전/오후가 없으면 1~6시는 오후, 7~11시는 오전으로 읽고, 날짜도 없으면 다가오는 시각으로 정해요.
- 다른 앱(메신저, 메모, 브라우저 등)에서 글을 **공유 → "PinTodo에 할 일로 추가"**를 고르면 첫 줄은 제목, 나머지는 메모로 빠른 추가 시트가 열려요. 여기서도 날짜를 읽어 일정 칩을 미리 골라 둬요.
- 반복 할 일은 "오늘 완료"를 누르면 다음 회차에 다시 떠요.
- 정확한 알람(`AlarmManager`)을 써서 정해진 시각에 맞춰 알림을 띄우고 내려요. **알람 및 리마인더** 권한이 꺼져 있으면 몇 분 늦을 수 있는 일반 알람으로 대신해요.

### 홈 화면 위젯 · 빠른 설정 타일
- **위젯**: 진행 중·알림 없는·예정인 할 일을 최대 8개까지 보여줘요. 체크를 누르면 완료되고, 알림 중인 할 일은 오른쪽 버튼으로 바로 미뤄요. 할 일을 누르면 수정 화면, 빈 곳을 누르면 앱이 열려요. **+** 버튼으로 바로 추가할 수 있어요.
  - 한 줄짜리처럼 작게 줄이면 가장 위의 할 일 하나와 개수만 보여주는 요약형으로 바뀌어요(Android 12+).
  - 할 일이 바뀌는 순간 바로 갱신돼요(RemoteViews로 직접 그림).
- **빠른 설정 타일**: 알림창을 내려 "할 일 추가" 타일을 누르면, 앱을 열지 않고 하단 시트에서 바로 추가해요.
- 둘 다 **설정 > 알림창 · 홈 화면**에서 버튼 한 번으로 추가할 수 있어요.

### 앱 화면
- 하단 메뉴: **할 일 / 기록 / 설정**
  - **할 일**: 진행 중 / 예정 / 기간 종료로 나눠 보여줘요. 카드를 **오른쪽으로 밀면 완료**(실행 취소 가능), **왼쪽으로 밀면 미루기**예요. 진행 중인 할 일은 남은 시간을 보여주고, 1시간 안에 끝나면 빨간색으로 표시해요. 기간이 끝난 할 일은 **다시 하기**로 지금부터 다시 띄울 수 있어요.
  - **기록**: 이번 주 요일별 완료 수와 지난주 비교, 제목·메모 검색, 날짜별 완료 목록. 체크를 다시 누르면 되돌려요.
  - **설정**: 미루기 선택지, 새 할 일 기본값(알림 받기·고정·알림 방식), 위젯·타일 추가, 스마트워치, 백업·복원, 권한 등을 관리해요. **버전**을 누르면 업데이트 기록을 볼 수 있어요.
- **백업·복원**: 휴대폰의 Google 백업이 켜져 있으면 새 휴대폰에 앱을 설치할 때 할 일과 설정이 **자동으로 옮겨져요.** 설정 > 백업에서 JSON 파일로 직접 저장하고 되돌릴 수도 있어요(서버 없이 원하는 곳에 저장).
- 처음 실행하면 **알림 → 알람 및 리마인더 → 배터리** 순서로 필요한 허용을 하나씩 안내해요.
- 수정 중에 닫거나, 알림·위젯으로 다른 할 일을 열면 **저장하지 않은 내용을 버릴지 먼저 물어요.**
- TalkBack: 카드의 완료·미루기·다시 하기를 동작 메뉴로 쓸 수 있고, 휠은 "다음 값/이전 값"으로 바꿀 수 있어요.
- 디자인은 토스 디자인 시스템(TDS)을 참고했어요. 회색 배경에 테두리 없는 흰 카드, 파란 포인트 색, 큰 버튼과 하단 시트를 썼어요. 다크 모드를 지원하고, 설정에서 배경화면 색상(Material You)을 쓰도록 바꿀 수 있어요.
- 기록·설정 탭에서 뒤로가기를 누르면 할 일 탭으로 돌아가요. 할 일 탭에서 한 번 더 누르면 앱이 닫혀요.
- 알림 권한, 알람 및 리마인더 권한이 꺼져 있거나 배터리 절전 예외가 아니면 앱 상단에 안내 배너가 떠요.

## 설치 방법

아직 Google Play에 출시하기 전이라 지금은 **직접 빌드해서 설치**해요.

### 1. 준비물
- JDK 17 이상
- Android SDK (Android Studio를 설치하면 함께 설치돼요)

### 2. 빌드

```bash
git clone https://github.com/ganglike248/pinTodo.git
cd pinTodo

# Android SDK 경로 지정 (Android Studio로 열면 자동으로 생성돼요)
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties

./gradlew assembleSideload
```

빌드가 끝나면 `app/build/outputs/apk/sideload/app-sideload.apk` 파일이 생겨요.

> `sideload`는 직접 설치용(디버그 키 서명)이에요. Google Play용은 `./gradlew bundleRelease`로 업로드 키 서명 AAB를 만들어요(키는 저장소에 없음, `store/RELEASE.md` 참고).

### 3. 폰에 설치

**방법 A: USB로 설치 (adb)**
1. 폰에서 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 눌러 개발자 모드를 켜요.
2. **설정 → 개발자 옵션 → USB 디버깅**을 켜고 USB로 연결해요.
3. 아래 명령을 실행해요.
   ```bash
   adb install -r app/build/outputs/apk/sideload/app-sideload.apk
   ```

**방법 B: 파일로 설치**
1. APK 파일을 폰으로 옮겨요(카카오톡 나에게 보내기, 구글 드라이브 등).
2. **내 파일** 앱에서 APK를 열고 "출처를 알 수 없는 앱 설치"를 허용해요.

설치하면 앱 서랍에 **"PinTodo"**로 나타나요. 삼성 런처는 새 앱을 앱스 화면 맨 마지막 페이지에 넣기 때문에, 안 보이면 검색창에 "Pin"을 입력해 보세요.

### 4. 처음 실행 후 설정 (권장)

| 설정 | 이유 |
|---|---|
| **알림 권한 허용** | 허용하지 않으면 알림이 아예 뜨지 않아요. |
| **알람 및 리마인더 허용** | Android 14부터는 기본으로 꺼져 있어요. 꺼져 있으면 시작·종료·미루기 알림이 몇 분 늦을 수 있어요. 앱 상단 배너의 **"허용하기"** 버튼으로 설정 화면을 열 수 있어요. |
| **배터리 절전 예외 등록** | 삼성의 절전 기능(딥 슬립)이 앱을 재우면, 지운 알림을 다시 띄우거나 예약 시각에 알림을 띄우는 동작이 늦어지거나 막힐 수 있어요. 앱 상단 배너의 **"설정 열기"**를 눌러 **배터리 > 제한 없음**으로 바꿔 주세요. |

## 알아둘 점

- 설정에서 앱을 **강제 종료**하면 시스템이 알림을 모두 지워요. 이건 앱에서 막을 수 없지만, 앱을 다시 열면 알림이 복원돼요.
- 같은 앱 알림이 여러 개면 안드로이드가 알림창에서 자동으로 하나로 묶어요. 묶음을 펼치면 할 일마다 완료·미루기 버튼이 보여요.
- 데이터는 기기 안(SharedPreferences)에만 저장돼요. 앱을 삭제하면 할 일도 함께 지워져요.

### 동작 흐름

```
할 일 저장 / 예약 시각 도달 / 부팅·업데이트 / 앱 실행
                      │
                      ▼
                  Sync.run()
      ┌───────────────┼──────────────────┐
      ▼               ▼                  ▼
 표시 구간이면      구간이 아니면       다음 상태 변경 시각에
 알림 게시          알림 내림           정확한 알람 예약
 (처음이면 울림,
  아니면 조용히)

알림을 밀어서 지움 ──▶ 고정이면 그 알림만 조용히 다시 게시
```

## 버전 관리

- 스토어 출시 전까지는 **0.x** 버전을 써요. 정식 출시할 때 1.0.0으로 올려요.
- 버전은 `version.txt`와 `app/build.gradle.kts`의 `versionName`에 함께 기록해요. 버전을 올릴 때마다 `versionCode`도 1씩 올려요.
- 커밋 메시지는 `vX.Y.Z - type: 요약` 형식으로 써요(예: `v0.2.1 - fix: 반복 알림 종료 시각 오류 수정`).
