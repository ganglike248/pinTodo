# 📌 고정 투두 (pinTodo)

**완료할 때까지 알림창에서 사라지지 않는 안드로이드 할 일 앱**

할 일을 추가하면 알림창에 고정됩니다. 옆으로 밀어도, "모두 지우기"를 눌러도 다시 나타나고, **'완료' 버튼을 눌러야만** 사라져요.

> 현재 버전: **v0.1.0** (정식 출시 전) · Android 8.0(API 26) 이상 · 개인용(Play 스토어 미배포)

<br>

## 만든 이유

갤럭시 기본 리마인더나 캘린더 앱은 할 일을 알림으로 보여주지만, **알림을 옆으로 밀거나 지우면 그대로 사라지고 다시 뜨지 않아요.** 무심코 알림창을 정리하다 보면 해야 할 일까지 같이 지워져 버립니다.

"끝낼 때까지 눈앞에 계속 떠 있는 할 일"이 필요해서 만들었어요.

### 왜 일반적인 '고정 알림'만으로는 안 될까

안드로이드에는 원래 지울 수 없는 알림(`ongoing`)이 있지만, **Android 14(One UI 6)부터 사용자가 이런 알림도 밀어서 지울 수 있게 바뀌었어요.** 그래서 이 앱은 다음 방식을 함께 써요.

1. 알림이 지워지는 순간을 감지해(`deleteIntent`) **즉시 조용히 다시 띄우기**
2. 재부팅, 앱 업데이트, 시간 변경 뒤에도 **알림 자동 복원하기**
3. 앱이 강제 종료되어 알림이 사라졌으면 **앱을 열 때 복원하기**

<br>

## 주요 기능

### 알림창 고정
- 할 일마다 알림이 하나씩 생겨요.
- 밀어서 지워도 바로 다시 나타나요. 고정을 끄면 밀었을 때 이번 회차만 숨겨요.
- 알림에서 바로 **완료**하거나 **1시간 뒤에**로 미룰 수 있어요.
- 알림을 누르면 해당 할 일의 수정 화면이 열려요.

### 소리·진동은 처음 한 번만
- 알림 방식은 **무음 / 소리 / 진동 / 소리+진동** 중에서 고를 수 있어요.
- 소리와 진동은 **할 일이 처음 뜰 때 한 번만** 울려요. 밀었다가 다시 뜰 때, 재부팅이나 업데이트로 복원될 때는 조용히 표시돼요.
- 반복 할 일의 새 회차가 시작될 때와 미루기가 끝날 때만 다시 한 번 알려요.

### 표시 기간 설정
| 일정 | 설명 | 예시 |
|---|---|---|
| **한 번** | 시작과 종료 시각을 지정해요. 비워두면 지금부터 완료할 때까지 표시돼요. | 오늘 14:00 ~ 18:00 |
| **반복** | 요일과 하루 중 시간대를 지정해요. 그 시간에만 알림이 떠요. | 평일 09:00 ~ 18:00 |

- 시작 시각은 빠른 선택(30분 뒤, 1시간 뒤, 내일 아침 9시)으로도 정할 수 있어요.
- 반복 요일은 매일, 평일, 주말을 한 번에 고를 수 있어요.
- 반복 할 일은 "오늘 완료"를 누르면 다음 회차에 다시 떠요.
- 정확한 알람(`AlarmManager`)을 써서 정해진 시각에 맞춰 알림을 띄우고 내려요.

### 앱 화면
- Material 3 디자인을 썼고, Android 12 이상에서는 배경화면 색에 맞춰 앱 색이 바뀌어요(Material You). 다크 모드도 지원해요.
- 목록은 **진행 중 / 예정 / 기간 종료 / 완료됨** 섹션으로 나뉘어요.
- 카드를 오른쪽으로 밀면 완료되고, 실수했으면 **실행 취소**로 되돌릴 수 있어요.
- 알림 권한이 꺼져 있거나 배터리 절전 예외가 아니면 앱 상단에 안내 배너가 떠요.

## 설치 방법

Play 스토어에 올리지 않은 개인용 앱이라 **직접 빌드해서 설치**해요.

### 1. 준비물
- JDK 17 이상
- Android SDK (Android Studio를 설치하면 함께 설치돼요)

### 2. 빌드

```bash
git clone https://github.com/ganglike248/pinTodo.git
cd pinTodo

# Android SDK 경로 지정 (Android Studio로 열면 자동으로 생성돼요)
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties

./gradlew assembleRelease
```

빌드가 끝나면 `app/build/outputs/apk/release/app-release.apk` 파일이 생겨요.

> 개인용이라 release 빌드도 **디버그 키로 서명**해요. 별도 키스토어를 만들 필요가 없어요.

### 3. 폰에 설치

**방법 A: USB로 설치 (adb)**
1. 폰에서 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 눌러 개발자 모드를 켜요.
2. **설정 → 개발자 옵션 → USB 디버깅**을 켜고 USB로 연결해요.
3. 아래 명령을 실행해요.
   ```bash
   adb install -r app/build/outputs/apk/release/app-release.apk
   ```

**방법 B: 파일로 설치**
1. APK 파일을 폰으로 옮겨요(카카오톡 나에게 보내기, 구글 드라이브 등).
2. **내 파일** 앱에서 APK를 열고 "출처를 알 수 없는 앱 설치"를 허용해요.

설치하면 앱 서랍에 **"고정 투두"**로 나타나요. 삼성 런처는 새 앱을 앱스 화면 맨 마지막 페이지에 넣기 때문에, 안 보이면 검색창에 "투두"를 입력해 보세요.

### 4. 처음 실행 후 설정 (권장)

| 설정 | 이유 |
|---|---|
| **알림 권한 허용** | 허용하지 않으면 알림이 아예 뜨지 않아요. |
| **배터리 절전 예외 등록** | 삼성의 절전 기능(딥 슬립)이 앱을 재우면, 지운 알림을 다시 띄우거나 예약 시각에 알림을 띄우는 동작이 늦어지거나 막힐 수 있어요. 앱 상단 배너의 **"예외 등록"** 버튼으로 바로 설정할 수 있어요. |

<br>

## 알아둘 점

- 설정에서 앱을 **강제 종료**하면 시스템이 알림을 모두 지워요. 이건 앱에서 막을 수 없지만, 앱을 다시 열면 알림이 복원돼요.
- 같은 앱 알림이 여러 개면 안드로이드가 알림창에서 자동으로 하나로 묶어요. 묶음을 펼치면 할 일마다 완료·미루기 버튼이 보여요.
- 데이터는 기기 안(SharedPreferences)에만 저장돼요. 앱을 삭제하면 할 일도 함께 지워져요.

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 언어 | Kotlin 2.2 |
| UI | Jetpack Compose, Material 3 (Compose BOM 2025.10.00) |
| 알림 | `NotificationManager`, 알림 방식별 채널 + 조용한 재게시 채널 |

## 프로젝트 구조

```
app/src/main/java/com/ganglike/pintodo/
├── data/
│   ├── Todo.kt          # 할 일 모델 + 표시 구간·상태 계산 (한 번/반복, 미루기, 회차)
│   └── TodoStore.kt     # 저장소 (SharedPreferences JSON, StateFlow)
├── notify/
│   ├── Sync.kt          # 저장된 할 일 ↔ 실제 알림/알람 상태 맞추기 (핵심 로직)
│   ├── Notifier.kt      # 알림 채널 구성 + 알림 생성
│   ├── Receivers.kt     # 알림 버튼·스와이프 삭제 / 예약 알람 / 부팅·업데이트·시간 변경 수신
│   └── Actions.kt       # 완료·저장·삭제 공통 동작
└── ui/
    ├── MainActivity.kt  # 진입점, 화면 전환, 실행 취소
    ├── ListScreen.kt    # 목록 화면 (섹션, 스와이프 완료, 안내 배너)
    ├── EditScreen.kt    # 추가/수정 화면
    ├── Pickers.kt       # 날짜·시각 선택 다이얼로그
    ├── Components.kt    # 공통 UI 컴포넌트
    ├── Format.kt        # 날짜·일정 문구 포맷
    └── Theme.kt         # Material 3 테마 (Material You)
```

### 동작 흐름

```
할 일 저장 / 예약 시각 도달 / 부팅·업데이트 / 앱 실행
                      │
                      ▼
                  Sync.run()
      ┌───────────────┼──────────────────┐
      ▼               ▼                  ▼
 표시 구간이면      구간이 아니면       다음 상태 변경 시각에
 알림 게시          알림 내림           정확한 알람 예약
 (처음이면 울림,
  아니면 조용히)

알림을 밀어서 지움 ──▶ 고정이면 그 알림만 조용히 다시 게시
```

## 버전 관리

- 버전은 `version.txt`와 `app/build.gradle.kts`의 `versionName`에 함께 기록해요. 버전을 올릴 때마다 `versionCode`도 1씩 올려요.
- 커밋 메시지는 `vX.Y.Z - type: 요약` 형식으로 써요(예: `v0.1.1 - fix: 반복 알림 종료 시각 오류 수정`).
