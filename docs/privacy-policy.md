# PinTodo 개인정보처리방침

시행일: 2026년 10월 6일

PinTodo(이하 "앱")는 사용자의 개인정보를 **수집하지 않습니다.**

## 1. 수집하는 정보
앱은 이름, 연락처, 위치, 기기 식별자, 사용 기록 등 어떠한 개인정보도 수집하거나 외부로 전송하지 않습니다.
앱에는 광고, 분석(통계), 로그인, 외부 서버가 없습니다.

## 2. 기기에 저장되는 정보
사용자가 입력한 할 일(제목, 메모, 체크리스트, 일정)과 앱 설정은 **사용자의 기기 안에만** 저장됩니다.
개발자를 포함한 누구도 이 정보에 접근할 수 없습니다. 앱을 삭제하면 함께 삭제됩니다.

## 3. 백업
- **Android 자동 백업**: 기기의 Google 백업이 켜져 있으면, Android 시스템이 할 일과 설정을 사용자의 Google 계정에 암호화해 백업합니다. 이 백업은 Google이 관리하며 개발자는 접근할 수 없습니다. 기기 설정에서 끌 수 있습니다.
- **백업 파일**: 사용자가 설정 > 백업에서 직접 만든 파일은 사용자가 고른 위치에만 저장됩니다.

## 4. 사용하는 권한
| 권한 | 용도 |
|---|---|
| 알림 | 할 일을 알림창에 표시 |
| 알람 및 리마인더 | 정한 시각에 알림을 띄우고 내리기 |
| 부팅 완료 수신 | 휴대폰을 다시 켠 뒤 알림 복원 |
| 진동 | 할 일이 처음 뜰 때 진동 |

권한은 위 기능에만 쓰이며, 어떤 정보도 외부로 보내지 않습니다.

## 5. 아동의 개인정보
앱은 어떤 사용자의 정보도 수집하지 않으므로 아동의 정보도 수집하지 않습니다.

## 6. 방침의 변경
이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 알립니다.
