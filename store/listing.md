## 2. 간단한 설명 (80자)
```
완료할 때까지 알림창에서 사라지지 않는 할 일. 밀어서 지워도 다시 떠요.
```

## 3. 자세한 설명 (4000자)
```
알림을 무심코 밀어서 지웠다가 할 일을 놓친 적 있나요?
PinTodo는 할 일을 끝낼 때까지 알림창에 고정해 둡니다. 밀어서 지워도, '모두 지우기'를 눌러도 다시 나타나고, [완료]를 눌러야만 사라져요.

■ 알림창 고정
• 할 일마다 알림이 하나씩, 완료할 때까지 그대로
• 알림에서 바로 [완료] [10분 뒤] [미루기…]
• 소리·진동은 처음 한 번만. 다시 뜰 때는 조용히
• 하루 안에 끝나는 할 일은 남은 시간이 실시간으로 줄어들어요

■ 쉽게 추가
• "내일 오후 3시 회의", "금요일까지 보고서"처럼 쓰면 일정이 자동으로 맞춰져요
• 알림창 빠른 설정 타일, 홈 화면 위젯, 다른 앱에서 공유하기로 바로 추가
• 체크리스트로 장보기·준비물을 한 할 일에 묶어서
• 색 라벨로 한눈에 구분

■ 원하는 일정
• 한 번: 시작·종료 시각 지정, 비워 두면 지금부터 완료할 때까지
• 반복: 매주·격주·매월(말일 포함)·며칠마다, 하루 중 시간대 지정
• 반복을 날짜나 횟수로 끝내기

■ 그 밖에
• 갤럭시 워치 등 스마트워치로도 알림
• 기록 탭에서 완료한 일과 이번 주 통계
• 휴대폰을 바꿔도 Google 백업 또는 백업 파일로 그대로
• 다크 모드, 배경화면 색상(Material You)

■ 개인정보
계정도, 광고도, 서버도 없어요. 모든 할 일은 내 휴대폰에만 저장됩니다.
```

### 데이터 보안 양식
- 앱에서 사용자 데이터를 수집하거나 공유하나요? → **아니요**
  (할 일은 기기 안에만 저장. Android 자동 백업은 시스템 기능이라 '수집'에 해당하지 않음)
- 전송 중 암호화 / 삭제 요청: 수집하지 않으므로 해당 없음

### 권한 관련
- `SCHEDULE_EXACT_ALARM`: 별도 신고서 필요 없음 (사용자가 직접 허용하는 권한)
- `USE_EXACT_ALARM`, `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`: 사용하지 않음 (v0.4.2에서 제거)
- 포그라운드 서비스: 없음
